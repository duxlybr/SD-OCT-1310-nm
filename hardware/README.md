# Hardware

Physical documentation of the SD-OCT 1310 nm system.

| Folder / file | Content |
|---|---|
| [`BOM.md`](BOM.md) | Bill of materials |
| [`cad/fusion360/`](cad/fusion360/) | Autodesk Fusion 360 virtual assembly (`.f3d`) |
| [`cad/step/`](cad/step/) | STEP exports of each subassembly (spectrometer, interferometer, reference arm, sample arm, scanner) |
| [`3d_printing/`](3d_printing/) | Printable parts (`.stl` + source), with material and print settings |
| [`wiring/`](wiring/) | Electrical connections and synchronization signals |

Manufacturer STEP files of catalog components (e.g. Thorlabs) are subject to
the manufacturer's terms; link to the product page instead of redistributing
them when in doubt.
