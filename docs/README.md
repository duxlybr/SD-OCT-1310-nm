# Documentation

describe **how** the system is built, calibrated, characterized and
operated. Measured results are kept in [`../characterization/`](../characterization/).

| 5 | [Operation and acquisition](05_operation_and_acquisition.md) | Timing, acquisition parameters, data rates |
